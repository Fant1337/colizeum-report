# Colizeum Reports

Windows-программа для формирования отчёта смены по скриншоту LGS.

## Что умеет

- выбор сдающего и принимающего администратора;
- главный экран с карточками пяти администраторов;
- вставка скриншота LGS прямо из буфера через `Ctrl+V`;
- распознавание сумм со скриншота LGS;
- обязательная проверка и исправление сумм;
- расчёт строк Telegram-отчёта;
- заполнение существующей рабочей таблицы Excel;
- блокировка изменений прошлых дней, формул, строк «Итого» и посторонних ячеек;
- резервная копия таблицы перед каждой записью;
- копирование готового отчёта в Telegram.
- личная статистика администратора по PIN-коду;
- расчёт смен, выручки, кальянов и предварительной зарплаты за период.

## Расчёт оплаты

До 15 000 ₽ выручки — 2 500 ₽ за смену; от 15 000 ₽ — 2 700 ₽; от 18 000 ₽ — 2 900 ₽; от 20 000 ₽ — 3 000 ₽; от 30 000 ₽ — 3 250 ₽. За каждый кальян добавляется 250 ₽. Периоды: 1–15 и 16–последний день месяца.

## Сборка с iPhone через GitHub

1. Создайте приватный репозиторий `colizeum-reports`.
2. Загрузите всё содержимое этой папки в корень репозитория.
3. Откройте вкладку **Actions** → **Build Windows EXE** → **Run workflow**.
4. После зелёной галочки откройте запуск и скачайте Artifact `Colizeum-Reports-Windows`.
5. Распакуйте ZIP на компьютере клуба и запустите `ColizeumReports.exe`.

Windows может показать SmartScreen, потому что EXE не подписан платным сертификатом разработчика. Нажмите «Подробнее» → «Выполнить в любом случае».

## Безопасность таблицы

Программа записывает только B, E, G, H, I, K, L и N в строке выбранной смены. Формулы C, D, F, J, M и строки «Итого» не изменяются. Перед заменой исходного файла проверяются все формулы книги и создаётся резервная копия.

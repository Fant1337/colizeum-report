# Colizeum Reports

Windows-приложение для подготовки сменного отчёта из скриншота LGS, записи разрешённых значений в существующую книгу Excel и копирования текста для Telegram.

## Сборка Windows EXE с iPhone через GitHub

Для сборки на компьютере ничего устанавливать не нужно. GitHub Actions соберёт приложение на сервере Windows.

1. Загрузите содержимое этой папки в корень репозитория GitHub. Сохраните папку `.github/workflows`.
2. Откройте репозиторий → **Actions** → **Build Windows EXE**.
3. Нажмите **Run workflow**, выберите ветку `main`, подтвердите запуск.
4. Дождитесь зелёной галочки. Откройте завершённый запуск и скачайте Artifact `Colizeum-Reports-Windows`.
5. На Windows распакуйте ZIP полностью и запустите `ColizeumReports.exe`. Не перемещайте EXE отдельно от остальных файлов: рядом нужна папка `tessdata`.

Если сборка красная, откройте шаг **Publish portable EXE**, раскройте текст ошибки и исправьте её до скачивания артефакта. В текущей версии проекта исправлена ошибка C# многострочной строки, ранее останавливавшая компиляцию.

## Работа администратора

1. Выберите карточку администратора.
2. Укажите дату смены, день/ночь и того, кто принимает смену.
3. Скопируйте экран LGS и нажмите **Ctrl+V** или выберите изображение кнопкой **Выбрать скриншот файлом**.
4. Проверьте распознанные суммы. Программа показывает нераспознанные поля и расхождение, если общая выручка не равна наличным плюс эквайринг.
5. Заполните значения, которых нет на скрине: сбор, кальяны, доп. гость ПС, конверт и остаток наличных.
6. Подключите рабочий файл Excel кнопкой **Выбрать рабочую таблицу Excel**. Путь запоминается для текущей учётной записи Windows.
7. Нажмите **Заполнить Excel**. Приложение сделает копию книги и откроет её после записи.
8. Нажмите **Скопировать отчёт для Telegram** и вставьте текст в группу Telegram.

Приложение не отправляет сообщения в Telegram автоматически: оно подготавливает текст, который администратор проверяет и вставляет сам.

## Формулы и защита Excel

В строке выбранной смены программа записывает только B, E, G, H, I, K, L и N. Она проверяет формулы всей книги и отменяет запись, если меняется любая формула или ячейка за пределами разрешённых столбцов выбранной строки. Строка «Итого» защищена. Даты раньше сегодняшней блокируются. Перед сохранением создаётся резервная копия исходной книги в папке `Резервные копии Colizeum Reports`.

Сопоставление книги: C, D, F, J и M — формулы; столбец A содержит дату; строки каждой даты состоят из двух смен и итоговой строки. Названия листов месяцев задаются в именительном падеже, например «ОКТЯБРЬ».

## Расчёт отчёта и оплаты

- Итог за смену = общая выручка LGS + онлайн-платежи.
- Безнал = онлайн-платежи + эквайринг.
- Игровое время = наличные + безнал − еда/бар.
- Ставка за смену по итогу выручки: до 15 000 ₽ — 2 500 ₽; от 15 000 ₽ — 2 700 ₽; от 18 000 ₽ — 2 900 ₽; от 20 000 ₽ — 3 000 ₽; от 30 000 ₽ — 3 250 ₽.
- За каждый кальян добавляется 250 ₽.
- Периоды статистики: 1–15 числа с выплатой 20 числа; 16–последний день месяца с выплатой 5 числа следующего месяца.

## Локальная статистика и данные

Статистика и PIN сохраняются локально на этом компьютере в профиле Windows. Между компьютерами данные не синхронизируются. PIN хранится в виде хеша, но при первом входе приложение не может удостовериться, что выбран именно владелец карточки: любой пользователь компьютера может первым установить PIN для ещё не настроенного администратора. Для общей статистики команды потребуется отдельное защищённое хранилище и подтверждение личности.

Скриншоты LGS временно обрабатываются на компьютере и не отправляются в сеть. Для первой сборки GitHub Actions скачивает языковые файлы OCR. В распакованном приложении они лежат в `tessdata`.

## Запуск на Windows

После распаковки запускайте `ColizeumReports.exe` из папки приложения. SmartScreen может показать предупреждение, так как сборка не подписана сертификатом разработчика.
